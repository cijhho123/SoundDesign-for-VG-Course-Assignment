# Sound Design for Video Games Final Assignment
This repository contains the final project for the Audio Design course, focusing on the implementation of a complete audio environment for a retro-futuristic space-themed game. The work includes original music, sound effects, voiceover assets, and Foley recordings. All assets were developed and produced to meet both creative and technical standards suitable for integration in a working game environment.

## Project Overview
The project explores a high-energy, retro-style audio direction inspired by 1980s arcade games. The music and sound design support a fast-paced space combat setting, with careful attention to reinforcing gameplay tension, player feedback, and overall immersion.

## Features
### Original Music Composition
Synth-based tracks produced using virtual analog instruments. Three music loops were created for the title menu, active gameplay, and game over screens.

### Sound Effects
Designed to align with gameplay actions and atmosphere:
- Player sound effects for shooting, movement, and UI interaction
-Distinct audio profiles for enemy types, using synthetic and processed vocal effects
- Game state indicators such as start, retry, and game over

### Voice Dialogue
Dialogue lines were written and recorded to match UI events using the active format script structure.

### Foley and Hybrid Design
Several effects were created using Foley recordings (e.g., arcade buttons, typing, chair movement) layered with digital processing to match the game's setting.

## Technical Specifications
- All audio files are provided in WAV format: 44.1kHz, 16-bit, mono or stereo as required
- Loudness normalized to -23 LUFS
- Clean starts and ends (no unintended silence or distortion)
- Loopable tracks where appropriate
